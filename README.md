# CourierFlow - Mini Courier Booking System

## Overview

CourierFlow is a full-stack courier management system that allows customers to create courier bookings, track shipments, and view booking status. Administrators can approve bookings, update shipment status, and manage all courier records.

## Features

### Customer Features

* User Registration
* User Login with JWT Authentication
* Create Courier Booking
* Track Shipment using Tracking ID
* View Personal Booking Dashboard
* Real-time Booking Updates

### Admin Features

* Admin Login
* View All Bookings
* Approve or Reject Bookings
* Generate Tracking IDs
* Update Shipment Status
* Real-time Dashboard Updates

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
